# claude-clip-command

Claude Code のターミナル画面で使う、小さなプラグイン（MOD）です。Claude が「実行してください」と示したコマンドをクリップボードへ入れ、入力欄にも置きます。
返答の末尾に利用者が実行するコマンド（`! ` で始まるコードブロック）があると、ふつうは選択してコピーし、手で貼り付けることになります。
このプラグインはそのブロックをクリップボードへ入れ、入力欄が空ならそこにも置くので、利用者がその文のまま Enter を押すだけで、プラグインが実行して結果をモデルに渡します。

English: [README.md](README.md)

画面に出る文言は日本語です。

## 使いどころ

- Claude が返答の最後に実行してほしいコマンドを書き、そのたびに手でコピーして貼り付けているとき。
- そのコマンドの実行結果を、自分で貼り付けずにモデルへ渡したいとき。
- Claude が `/rename my-session` のような 1 行のスラッシュコマンドを勧めてきて、打ち直さずに入力欄へ置いておきたいとき。

向かないとき: Windows で使う（未確認）、Claude を非対話で動かす（`claude -p`。置く先の入力欄がありません）、モデルが書いたコマンドを Enter で実行させたくない、のいずれかに当てはまる場合。

## 動くとこう見える

変更前: 返答の末尾に `! ` で始まるコードブロックがあります。その文を選択してコピーし、入力欄に貼って Enter を押します。

変更後: 「⌨️ 実行するコマンドを入力欄に置きました（Enter で実行）: …」という通知が出て、同じ文がすでに入力欄に入っています。Enter を押すとプラグインが実行し、送信文は `[MOD clip-command] ran: $ …` に続く終了コード・秒数・stdout・stderr に置き換わるので、モデルが出力を読めます。書きかけの文があるときは、代わりに「📋 実行するコマンドをクリップボードへ入れました（Cmd+V → Enter）: …」という通知が出て、書きかけはそのまま残ります。

## 動作条件

- Claude Code のプラグインフック（MOD）API を使っています。この API は早期提供の段階で、版によって変わる可能性があります。
- Claude Code 2.1.287〜2.1.289・macOS で開発・確認しました。
- **Windows は確認していません。** シェルを起動できないときは実行せず、文としてそのまま送ります。

## 導入

このリポジトリをマーケットプレイスとして登録して入れます。

```
claude plugin marketplace add i-noma-ru/claude-clip-command
claude plugin install clip-command@claude-clip-command
```

クローンして、そのセッションだけ読み込むこともできます。

```
claude --plugin-dir /path/to/claude-clip-command
```

クローンを全セッションで読み込むには、環境変数 `CLAUDE_CODE_PLUGIN_DIRS` に書いたディレクトリの中へこのフォルダを置きます。この環境変数は 2.1.288 で動きましたが、`claude --help` には出てこないので、変わる可能性があります。

## 動き

ターンの終わりに、中身が `! ` で始まる最初のコードブロックを探します（Claude Code のシェルモードと同じ書き出しです）。無ければ、`/rename my-session` のような 1 行のスラッシュコマンドだけのブロックを探します。

- 見つけた文をクリップボードへ入れます。
- 入力欄が空なら、下書きとして入力欄にも置きます。書きかけの文は上書きしません。
- どちらを行ったかを通知で知らせます。

シェル以外の言語指定（`diff` など）のブロック、複数行のスラッシュコマンド、`/tmp/x` のようなパスは対象外です。

使うには、利用者に実行を頼むコマンドを `! ` で始まるコードブロックに書くよう、モデルに指示しておきます（`CLAUDE.md` など）。

### 置いたコマンドの実行

`prompt.fill` で置いた文はただの文字で、Claude Code はシェルモードに切り替えません。そのため、プラグインが自分で実行します。

- 実行するのは、送信された文が**プラグインが入力欄に置いた `! ` コマンドと完全に一致**し、**利用者が入力欄で Enter を押した送信**のときだけです。
- `$SHELL -lc "<先頭の ! を除いたコマンド>"` を、セッションの作業ディレクトリで実行します。上限は 10 分です。
- 送信文を実行結果（`[MOD clip-command] ran: $ …`・終了コード・秒数・stdout・stderr）に置き換えるので、モデルが出力を読めます。
- 同じ文を 2 回は実行しません。利用者が自分で貼った文や打った文、スラッシュコマンド、ほかの経路からの送信は、そのまま通します。

**セキュリティ上の注意:** コマンドの文面はモデルが書いたものです。プラグインが勝手に実行することはなく、利用者が入力欄に出た文を見て Enter を押したときだけ実行します。ターミナルにコマンドを貼る前と同じように、Enter の前に内容を読んでください。この動きが要らない場合は、このプラグインを入れないか、Enter を押さずに入力欄を消してください。
